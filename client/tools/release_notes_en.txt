# English user-facing release notes, one line per merged PR:
#
#     <PR number>: <english note>
#     sha:<commit sha or ≥7-char prefix>: <english note>
#
# Every user-visible feat/fix/perf PR adds its line here (written by the
# PR author, in English). release_notes.py uses it instead of the commit
# subject — usually French — and warns in the workflow logs when an
# entry is missing. The `sha:` form covers a commit whose PR cannot be
# attributed (squash subject without a `(#N)` suffix and no
# `Merge pull request #N` ancestor). `#` lines are comments; no inline
# comments. For non-conventional commit subjects (no
# feat:/fix:/perf: prefix) the section must be tagged right after the
# key: `<PR>: [feat|fix|perf] <note>`. Entries for already-released PRs
# are inert — prune at release time.
#
