# English user-facing release notes, one line per merged PR:
#
#     <PR number>: <english note>
#
# Every user-visible feat/fix/perf PR adds its line here (written by the
# PR author, in English). release_notes.py uses it instead of the commit
# subject — usually French — and warns in the workflow logs when an
# entry is missing. `#` lines are comments; no inline comments.
# Entries for already-released PRs are inert — prune at release time.

182: Client updates now report progress and surface explicit errors instead of failing silently.
183: Catalog components can declare configurable parameters, editable from the client.
184: Component editing now exposes only the parameters declared by the catalog — internals stay read-only.
185: The sidebar PR registry no longer records non-existent pull request references.
186: Queued prompts gain a steer button to inject them into the running turn without cancelling it.
188: Fixed mesh background facets tinted with the accent's complementary color in the light theme.
189: Session diagram: roots of the same group are now placed contiguously.
190: Fixed unreadable code blocks in the light theme.
192: Sound alerts now offer a choice of presets per event — richer sounds synthesized live, no bundled audio files.
193: AgentReviewer component gains a `repos` parameter (JSON) for multi-repo watching, and a new `json` parameter type renders structured values into managed configs; workers can now request a local pre-push diff review via `agent-reviewer review`.
194: New accent intensity setting — soft or vivid variants of every accent color.
195: The backlog orchestrator is now fully configurable at runtime — toggles, worker and spawn settings, prompts, and repo workspaces persist to config.toml.
196: The MSI installer wizard now shows branded AgentControl artwork instead of the generic WiX default images.
197: Remote daemon updates no longer abort on the busy guard when the running daemon holds the port — foreign listeners stay protected, and the update dialog now warns that the connection drops and re-establishes.
198: PDF files now open in an embedded viewer — continuous-scroll canvas rendering, zoom controls, and a "open with system app" fallback for large files.
199: Resuming a session whose native agent was lost (daemon restart/update) now falls back to a fresh context instead of failing forever — the history is kept, a system note explains the relaunch, and dead agents no longer linger as green "working" sessions.
201: Components installed from the catalog now resynchronize their spec at daemon startup — newly declared parameters (e.g. `repos`), render templates and healthchecks appear on older installs while user values are preserved.
202: Native OS notifications when an agent finishes its turn, awaits your reply, or fails — per-type toggles, click focuses the app and opens the session (Android included, web excluded).
203: Background loads (pinned messages, conversation, file tree, queue bar, search) no longer pop a raw "connection lost" error on a transient connection drop — they wait for the reconnect or replay once, and reload silently when the link is back.
