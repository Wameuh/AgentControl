## Default Permission

Autorise la commande de diagnostic `stt_ping`
(squelette du plugin STT — spike d'intégration).

#### This default permission set includes the following:

- `allow-stt-ping`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`ac-stt:allow-stt-ping`

</td>
<td>

Enables the stt_ping command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`ac-stt:deny-stt-ping`

</td>

</td>
</tr>
