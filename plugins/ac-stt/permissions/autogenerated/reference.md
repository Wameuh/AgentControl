## Default Permission

Plugin STT : diagnostic `stt_ping` + gestion des modèles
téléchargeables (`stt_dl_*` — download à la demande depuis les
settings, Android only).

#### This default permission set includes the following:

- `allow-stt-ping`
- `allow-stt-dl-state`
- `allow-stt-dl-start`
- `allow-stt-dl-cancel`
- `allow-stt-dl-delete`
